# ストア掲載情報（日本語）

App Store Connect / Play Console にそのまま貼れる形でまとめてある。
機能を変えたらこのファイルも直すこと。

---

## 概要（Description）

> 上限 4,000 文字。以下は約 1,000 文字。

```
支出・収入・貯金を、ひとつの家計簿で。

アカウント登録は不要です。記録したデータは端末の中だけに保存され、外部のサーバーに送信されることはありません。

■ 支出と収入を分けて記録
金額を入れてカテゴリを選ぶだけ。日付は最初から今日が入っているので、いつもの記録は数タップで終わります。カテゴリは記録画面からその場で追加でき、アイコンは150種類以上から選べます。

■ 毎月・毎年の予算
全体の予算と、カテゴリごとの予算を設定できます。「毎月の食費は3万円、ただし12月だけ5万円」のように、その月だけ上書きすることも可能です。使いすぎていないかは、消化率と残額の両方で確認できます。

■ 固定費の自動記録
家賃・通信費・サブスクなど毎月決まって発生する支出を登録しておくと、期日が来たときに自動で記録されます。金額が毎月変わるものは「確認してから記録」を選べます。発生前のお知らせにも対応しています。
過去の分をまとめて入れたいときは、期間を指定して一括で追加することもできます。

■ 貯金の目標（買い切りで解放）
「来年3月までに20万円」のように、目的・目標金額・目標日を決めて積み立てられます。達成率、毎月必要な積立額、今のペースでの到達見込みを確認できます。

■ グラフで振り返る
カテゴリ別の内訳を円グラフで、月ごとの推移を年間レポートで確認できます。

■ バックアップと引き継ぎ
データはファイルに書き出して、クラウドストレージなどお好きな場所に保存できます。機種変更のときは、そのファイルから復元できます。表計算ソフトで見たいときは CSV でも書き出せます。

■ 買い切りについて
貯金機能の解放と広告の非表示は、一度のお支払いでご利用いただけます。月額課金ではありません。以前ご購入いただいている場合は「購入を復元」から引き継げます。

無料でご利用の場合、画面下部に広告が表示されます。広告の配信のために広告配信事業者が端末の識別子を取得しますが、家計簿として記録したデータ（取引・予算・固定費・貯金）が外部に送信されることはありません。
```

### 書くときに守ること

- **「一切通信しない」と書かない。** 広告SDKが識別子を送るため事実に反し、
  審査でも指摘対象になる。家計簿のデータと広告の識別子を分けて書く
- **他社アプリ名を出さない。** 比較・言及ともにリジェクト理由になる
- **Android や他プラットフォームに触れない**
- 未実装の機能を書かない（このアプリには銀行連携・レシート読み取り・共有機能はない）

## キーワード（Keywords）

> 上限 100 文字。カンマ区切り、**カンマの後に空白を入れない**（空白も1文字として数えられる）。
> アプリ名とサブタイトルの語は別に索引されるので、キーワードに重ねると枠の無駄になる。

**アプリ名に「家計簿」を含めない場合**（79/100 文字）

```
家計簿,家計,節約,貯金,貯蓄,予算,支出,収入,固定費,サブスク,生活費,やりくり,お小遣い,資産,管理,記録,シンプル,オフライン,収支,積立,簡単,自動
```

**アプリ名に「家計簿」を含める場合**（75/100 文字）

```
家計,節約,貯金,貯蓄,予算,支出,収入,固定費,サブスク,生活費,やりくり,お小遣い,資産,管理,記録,シンプル,オフライン,収支,積立,簡単,自動
```

単語は Apple 側で組み合わせて検索に使われるため、「資産管理」のような複合語を
入れるより「資産」「管理」を別々に入れたほうが枠を節約できる。

## サポートURL

**必須。実際に開けるページでなければならない**（審査で開かれる）。
リンク切れや工事中ページはリジェクト理由になる。

`docs/store/support.html` を用意してあるので、これを公開して URL を入れる。

### 公開のしかた（GitHub Pages が最短）

アプリ本体のリポジトリは Private なので、**公開用に別のリポジトリを作る**。

1. GitHub で公開リポジトリ（例 `kakeibo-support`）を Public で作る
2. `docs/store/` の中身（`support.html` → `index.html` にリネーム、`privacy.html`）を置く
3. Settings → Pages → Source を `main` / `root` にする
4. 数分後に `https://<ユーザー名>.github.io/kakeibo-support/` で開ける

問い合わせ先メールアドレスは、プレースホルダを実在するものに差し替えること。

## 「名」など個人情報の欄

App Store Connect が求める姓名・住所・電話番号は**実在の本人の情報**を入れる。
ここは代わりに用意できない。

| 欄 | 入れるもの | 注意 |
|---|---|---|
| 姓 / 名 | 本名（`姓` = 名字、`名` = 下の名前） | |
| App Review 連絡先 | 審査中に Apple が連絡できる本人の情報 | 電話・メールとも実際に繋がるもの |
| 販売者名 | 個人アカウントの場合は**法的な氏名がストアに公開される** | 本名を出したくない場合は法人化が必要 |

最後の点は見落としやすい。個人開発者として登録すると、
App Store の販売元表示に本名が出る。屋号やハンドルネームにはできない。
